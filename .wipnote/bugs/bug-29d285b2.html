Dashboard approve UI swallows 500 responses — silent data loss

Todo Medium Priority

Part Of:

  • trk-13e39042

Description

When POST .../feedback returns 500, the dashboard approve radio updates optimistically and surfaces no error: user believes slices are approved while nothing persisted (confirmed in production, v0.61.1). The review rail also rendered 8/8 approved from stale HTML checked attributes with zero backing rows. Fix: surface non-2xx responses on feedback writes (toast/inline error + revert the control), and derive review-progress from the same store the finalize gate reads so UI and gate cannot disagree.
