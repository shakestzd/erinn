Description

Snapshot construction uses linear hasEdge scans while appending derived track contains edges and reverse session implements edges. Complexity is O(sum track_size squared plus sum session_fanout squared), so the current 1,060-item benign endpoint can hide a 5,000-item cliff when work concentrates in one track/session. Use the existing composite edgeKeys membership map and add concentrated-fanout curve benchmarks.
