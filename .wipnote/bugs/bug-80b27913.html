WorktreeCreate observe-only registration breaks Agent(isolation=worktree); remove registration so CC creates worktrees natively

Todo Medium Priority

Part Of:

  • trk-93178cf4

Description

Claude Code WorktreeCreate is a replacement-on-registration hook: registering it replaces CC native git worktree creation; the hook must create the dir and print ONLY the absolute path to stdout. wipnote's handler (internal/hooks/missing_events.go WorktreeCreate) is observe-only — records a checkpoint and returns {continue:true} JSON, so CC stats the JSON as a path and worktree creation fails (live error: 'returned a path that is not a directory: {continue:true}'). Since CC creates worktrees natively when NO WorktreeCreate hook is registered, the durable fix is to REMOVE the WorktreeCreate registration from packages/plugin-core/manifest.json and regenerate ports. Leave WorktreeRemove (documented observational). Verified against code.claude.com/docs/en/worktrees + hooks docs. Takes effect next Claude session (hooks load at startup).
