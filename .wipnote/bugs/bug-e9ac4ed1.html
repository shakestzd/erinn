Description

A directory named pre-merge-backup with a 20260512 timestamp sits inside .wipnote holding 8 HTML work-item files. It is not gitignored. Current code paths miss it by accident rather than design: wipnote relevant misses it because ripgrep skips dot-prefixed directories by default, and core/graph/loader.go LoadAll misses it because it only walks the six known collection directories. But a naive recursive walk over .wipnote does include it — confirmed during an in-memory graph benchmark, where it inflated the parsed edge count to 3211 against the indexed 3096. Any future code that walks the store recursively inherits stale duplicate work items with no warning. Delete it, or ignore it explicitly rather than relying on two unrelated tools happening to skip dot directories.
