Description

sessionPromptLabel in core/db/session_repo.go returns the verbatim raw user prompt. When a prompt contains injected markup (task-notification, task-id, tool-use-id XML tags) or hook-injected timestamp newlines, that raw text becomes the resumable-session PromptLabel. The huh chooser (cmd/wipnote/claude_chooser.go) only trims+truncates via truncateTitle, so tags render literally and embedded newlines break the single-line menu layout. Fix: sanitize at retrieval (strip angle-bracket tags, collapse whitespace to single space, trim), pick first non-empty sanitized candidate, so all callers (TUI, text fallback, sessions resumable --json, dashboard) get clean single-line labels.
