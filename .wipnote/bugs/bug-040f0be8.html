Description

The documented install route errors with 'plugin source path is not a directory'. wipnote's marketplace.json declares path './wipnote', which Codex resolves against the marketplace ROOT, but the plugin actually lives one level deeper at .agents/plugins/wipnote/. wipnote's own parser codexPluginDirFromMarketplace resolves the same string manifest-relative, so the two disagree and only wipnote's bespoke copy path works. Verified live against codex-cli 0.147.0. Fix the declared path so the documented route works; that is a precondition for ever retiring the bespoke launcher code.
