Description

Add a single helper for wipnote-owned Git mutations that acquires a repo-scoped advisory lock before running index/ref-writing Git commands. Use it to serialize concurrent agents and CLIs before Git's own index.lock contention path is reached. CONSTRAINT: the advisory lock only serializes wipnote's own processes; external writers (IDE, gitstatus daemon, user git) do not honor it, so the existing runGitWithLockRetry backoff loop MUST be retained as a complementary layer. flock auto-releases on process death, so wipnote's own lock can never go stale -- this is the rationale for flock over a pidfile. Acceptance Criteria Concurrent wipnote processes are serialized via the advisory lock; runGitWithLockRetry is retained for external-writer contention; lock auto-releases if the holding process dies. Expected Behavior Two wipnote autocommits launched simultaneously never both enter git's index-writing path at once; if one process is killed mid-commit, the lock is released automatically and the next process proceeds.
