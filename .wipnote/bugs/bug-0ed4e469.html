Description

User confirms that in 'wipnote yolo --track ' runs, actual SOURCE/code file changes (not just .wipnote artifacts) end up on canonical main rather than the created worktree. Expected: code edits stay in the worktree (CWD=workDir); only .wipnote/*.html artifacts go to main (WIPNOTE_PROJECT_DIR=canonicalRoot, by design). Hypothesis: spawned subagents resolve edit targets via WIPNOTE_PROJECT_DIR (=main) or otherwise do not inherit the worktree CWD, breaking isolation. Investigate subagent CWD inheritance + how agents/hooks/system-prompt resolve the project/edit root under yolo.
