IsPlanFullyApproved (internal/db/plan_feedback.go) counts COUNT(DISTINCT section) over ALL action=approve rows and blocks if any has value!=true. UI SectionsJSON only tracks design/outline/slice-N, so an invisible slice-N-question-* (or critique/q-*) approve row blocks finalize while dashboard shows All approved with no recovery path. Fix: scope gate to design/outline/^slice-[0-9]+$ to match the UI's approvable section set. GH issue 122.
