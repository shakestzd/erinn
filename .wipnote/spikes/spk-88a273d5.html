The strongest strategic find in the survey. Claude Code's tracing beta emits a root interaction span per prompt, with tool and llm_request spans carrying agent_id AND parent_agent_id, nesting to any depth — a complete agent spawn tree emitted by the harness with no correlation work. That is wipnote's headline capability, upstream. Also: the active tool execution's W3C TRACEPARENT is inherited by Bash subprocesses, so every wipnote CLI call from a hook already has trace context in its environment. And hook spans report hook_event, duration_ms and num_blocking — direct instrumentation for write-lock contention. Evaluate what wipnote should consume versus keep deriving itself.
