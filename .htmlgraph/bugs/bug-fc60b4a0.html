Description

Per CodexPlugins.md (lines 266-270): Codex auto-reads marketplaces from: - repo marketplace at $REPO_ROOT/.agents/plugins/marketplace.json - personal marketplace at ~/.agents/plugins/marketplace.json Currently users must explicitly run 'codex marketplace add ' to register our marketplace. That's friction: 1. For repo contributors: no $REPO_ROOT/.agents/plugins/marketplace.json exists (ours is nested under packages/codex-marketplace/.agents/plugins/). 2. For end users of the htmlgraph CLI: 'htmlgraph codex --init' runs the add for them, but it's registered as a local-source marketplace rooted at ~/shakes's specific dev path — not portable across machines. Two improvements: A. Add an auto-discoverable repo marketplace at the htmlgraph REPO ROOT: .agents/plugins/marketplace.json Pointing at the plugin tree under packages/codex-marketplace/plugins/htmlgraph/ (after bug-b5b3c3ef restructures the tree). Any developer who clones the htmlgraph repo and runs codex from within it will auto-discover htmlgraph plugin without any setup commands. B. For end users without the repo: 'htmlgraph codex --init' should install the plugin tree to the user's personal marketplace location: Copy plugin to ~/.codex/plugins/htmlgraph-local/ Add entry to ~/.agents/plugins/marketplace.json with source.path './.codex/plugins/htmlgraph-local' (relative to /Users/shakes). This makes codex auto-discover without requiring 'codex marketplace add'. User can uninstall by removing those two files. Depends on bug-b5b3c3ef (restructure Codex plugin tree) landing first so A and B have a clean layout to point at.
