Description

build.go removes the installed binary then runs 'go build -o' over several seconds; during that window any concurrent caller (agy/Claude statusline, hooks) gets 'exit 127: not found'. Surfaced as an agy statusline error during dogfooding rebuilds. Fix: build to a temp path in the same dir, then os.Rename atomically into place.
