Agents kill healthy go test runs: full suite is silent ~6 min by design

Todo Medium Priority

Part Of:

  • trk-a30e8df4

Description

Incident: an agent babysitting 'go test ./...' interpreted minutes of silence as a stall and killed the run just before completion. Root cause: go test buffers per-package output and prints in package list order; cmd/wipnote sorts first AND is the slowest package (~320s from cold), so a from-cold full suite emits zero output for ~5-6 minutes, then everything at once. No guidance states the expected duration or that silence is normal, so agents' output-as-liveness heuristics false-trigger. Compounding: prior TMPDIR lease false-failures prime agents to suspect the suite. Expected: gate/test guidance (system prompt, code-quality skill, test-runner agent, orchestrator directives) must state the ~6-min silent baseline, forbid killing the suite on silence alone, and offer streaming options (go test -v/-json, or internal/... then cmd/... split) when progress visibility is needed.
