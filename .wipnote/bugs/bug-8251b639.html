Dev launcher (--dev) bypasses the explicit-intent chooser

Todo Medium Priority

Part Of:

  • trk-6a1f5362

Description

wipnote claude --dev short-circuits to launchClaudeDev (cmd/wipnote/claude.go case dev:) and never invokes resolveLaunchIntentForDefaultLaunch, which lives only in launchClaudeDefault. So dev sessions always launch in-place on the current branch with no intent prompt, defeating plan-311440bf's intentionality guarantee (separate planning/research from code-change sessions; no plan->code transition within one session). Likely also affects yolo and the codex/gemini/antigravity dev paths. Fix: route dev launches through the same intent resolution as the default launcher.
