Diagram blocks emit duplicate arrowhead marker defs when two diagrams share a page

Todo Low Priority

Part Of:

  • trk-a951e3c0

Description

plan/blocks/diagram.go writes its own defs/marker per block while referencing the shared svg.ArrowheadMarkerRef id, so a page with 2+ diagram blocks emits duplicate element ids. Functionally harmless since the defs are identical and url(#id) resolves to the first, but it is invalid HTML and cuts against slice 1's intent that the marker be defined once and shared. Options: hoist the def to the page shell, or scope the id per block instance.
