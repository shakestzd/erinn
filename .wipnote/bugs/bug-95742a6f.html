Description

build.go uses a fixed temp path (binaryPath+.tmp-build); two concurrent wipnote build runs can remove/rename each other's in-progress output. Use os.CreateTemp(installDir,...) for a unique per-process temp path. Follow-up to bug-8fd0fac2 (roborev 296).
