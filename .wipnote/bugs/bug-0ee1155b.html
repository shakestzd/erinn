Two CSS issues in the dashboard plan-review embed (feat-801f2273). (1) .plan-content has max-width:960px inherited from the standalone page; when the dashboard sidebars collapse the panel widens (1228px+) but content stays pinned at 960px, wasting space and clipping the dependency graph. Let content (cards + dep-graph) use the full panel width in the #plan-detail-body embed. Give the chat message area adequate, independently-scrollable height with the input pinned at the bottom.
