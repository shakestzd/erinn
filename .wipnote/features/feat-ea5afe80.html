Description

Two-line connected rounded-ribbon Claude Code statusline rendered via Oh My Posh. Line 1: path, git, active wipnote work item (WIPNOTE_ACTIVE). Line 2: model, context gauge + pct + token count, session duration, session cost. Wrapper omp-claude-wrapper.sh queries 'wipnote statusline --session' and strips the OSC title escape; two single-block configs (line1/line2) render as two rows since OMP newline does not survive the claude renderer. VS Code terminal font set to JetBrainsMono Nerd Font.
