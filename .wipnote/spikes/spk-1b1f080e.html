Description

The pure-Go SQLite driver is pinned at v1.37.1 in all three modules. The virtual-table subpackage that would give SQL over NDJSON in place first appears in v1.45.0, and the current release is v1.56.0 — a jump of up to nineteen minor versions on the dependency every table in the system runs through. The driver transpiles upstream SQLite, so a bump likely carries a new upstream engine version with it, and wipnote depends on specific behaviour there: write-ahead-logging mode, an enforced foreign-keys pragma with tests asserting it, a busy-retry layer, a lease-based write daemon, and a nineteen-step migration chain that just produced a silent-failure bug. Establish whether the bump is safe, whether the minimum vtab release is a safer target than the latest, and what actually breaks. Verify by building and testing, not by reading release notes.
