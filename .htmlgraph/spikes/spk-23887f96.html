Researcher: Investigated sub-agent Tool call nesting issue. Root cause: Claude Code architectural limit — subagents CANNOT spawn other subagents (Agent/Task tool is not available inside a subagent). This is documented at code.claude.com/docs/en/sub-agents and tracked in GitHub issues #4182 and #19077. All 12 HtmlGraph agents are subagents when invoked by the orchestrator, so NONE of them can use Agent/Task. The coder agents (haiku/sonnet/opus) have NO tools: field, meaning they inherit ALL tools — but the Agent tool is blocked by platform architecture regardless. The researcher, debugger, test-runner, roborev, codex-operator, copilot-operator, gemini-operator agents have explicit tools: lists that do NOT include Agent — consistent and correct. Bonus bug: debugger.md has color: orange which is an invalid Claude Code color value (valid: blue, cyan, green, yellow, magenta, red). Recommended fix: (1) coder agents should add explicit tools: lists excluding Agent to be self-documenting and prevent confusion; (2) fix debugger color: orange to color: red; (3) consider adding a comment in agent files noting Agent tool nesting is a platform limitation.
