collectSessionIDs runs before reindexSessions on a from-scratch rebuild, dropping implemented_in edges

Todo Medium Priority

Part Of:

  • trk-08dcbb33

Description

On a from-scratch database, collectSessionIDs executes before reindexSessions has populated the sessions table, so session IDs are not yet valid targets and implemented_in edges pointing at them are dropped by the validity gate. Measured on an isolated full reindex: 5 feature and 8 bug implemented_in edges lost this way. Distinct from the plans-directory gap filed alongside this — same symptom, different cause, and this one only manifests when the index is rebuilt from nothing rather than incrementally.
