WorktreeCreate hook fails on Claude Code native worktree isolation: missing worktree_base_path

Todo Medium Priority

Part Of:

  • trk-2e707ed1

Description

Dispatching a Claude Code subagent with isolation=worktree fails because the wipnote WorktreeCreate hook handler exits with 'missing worktree_base_path'. The harness's native worktree-spawn payload evidently lacks the field the handler requires (or names it differently). Handler should treat the field as optional / derive a default base path instead of hard-failing, since a failing hook blocks the entire isolation feature. Surfaced 2026-06-10 while trying to run two coder agents in parallel. Check core/hooks worktree-create handler and the hook payload contract in the Claude Code hooks doc.
