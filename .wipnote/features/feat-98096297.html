Description

Build a harness-neutral resumable-session index served by the persistent daemon: a query joining sessions to their work item returning {work_item_id, title, type, branch, exec_worktree_path, harness, last_activity, last_session_id, live?}. Expose as `wipnote sessions resumable [--json]` plus a daemon HTTP endpoint the dashboard and TUI consume. Rank by recency; mark items with a currently-live claim, covering the multi-harness liveness cases (a crashed Codex/Gemini session that never emitted its terminal event must not appear falsely live).
