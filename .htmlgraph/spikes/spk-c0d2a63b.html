Sonnet-coder: Fixed test isolation bug for worktree parent session ID (bug-8198f5ee). Root cause: CloudEvent.CWD was empty in tests, causing resolveWorktreeParentSession to fall back to os.Getwd() (the real git worktree CWD), read the live .active-session file, and attempt to INSERT a session with a parent_session_id that didn't exist in the isolated test DB. The FK constraint caused INSERT OR IGNORE to silently drop the row, making GetSession return no rows. Fix: set event.CWD=projectDir in existing tests + add TestSessionStartWorktreeParentSessionIDPopulated to cover the full upsert-with-parent path. Files changed: packages/go/internal/hooks/session_start_test.go. The production code (resolveWorktreeParentSession, upsertSession) was already correct.
