Description

Building the generic round-trip test surfaced a whole group of models.Node fields with NO writer and NO parser support at all: PlanTaskID, SpecRequirements, the Handoff fields, RequiredCapabilities, CapabilityTags, and the Context fields. Confirmed by grep, not inferred. They exist on the model, can be set in memory, and are discarded at the write boundary exactly like node Properties were. The round-trip test that was just added deliberately excludes them and documents the exclusion in its doc comment rather than silently working around it, so the gap is visible rather than hidden. Two things need establishing before fixing: which of these fields have real consumers today, and whether any consumer is silently receiving empty values and behaving as though that were meaningful — the pattern that made isOrphanFeature dead code. SpecRequirements and the Handoff fields are the ones most likely to have live readers in spec generation, compliance scoring, or work handoff. Fix by wiring them through the same shared renderPropAttrs core and parser sweep, then extend the round-trip test to cover them so the exclusion list shrinks to empty.
