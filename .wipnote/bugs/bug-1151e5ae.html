Daemon derived-op write path is a void: every socket op is discarded

Description

runWriterOnly wires apply.NewApplier against the daemon's own ephemeral in-memory projection, while the socket Reader answers from canonical files via readsrv. Nothing ever reads what the applier writes. Every socket-delivered agent_event.upsert, session.insert, feature.status and raw SQL op is discarded. This is larger in scope than the maintenance loops: it means ackMeansDurable returning true licenses a caller to skip its own write in favour of a write that goes nowhere. Callers must be audited to distinguish those skipping a canonical write from those skipping a merely derived one.
