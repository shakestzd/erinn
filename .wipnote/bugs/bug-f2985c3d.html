roborev job 3576 Medium on feat-36566570. D3 v7 selection.on listeners receive (event, datum), but the new plan_page.gohtml graph click and mouseover/mouseout handlers treat the first arg as the node id. So id is actually the event object: navigation targets slice-[object PointerEvent] and dependency highlighting queries with the wrong key, breaking node-card nav and dep-chain highlighting in the browser. Fix: change handlers to (event, id) and use the second arg as the node id (click, mouseover, mouseout).
