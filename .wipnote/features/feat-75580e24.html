The plan-review chat backend spawns claude -p from plan/planchat/backend.go, making it Claude-Code-only — the same one-harness asymmetry that ruled out artifact publishing and kept native span agent_id as corroboration rather than replacement. It also never worked the way it was intended to. Deprecate and remove it rather than carry a Claude-only surface in the review flow. Note this removes one of only two claude -p consumers in the tree, narrowing bug-0cdfa8e5 to compliance_auto.go alone, which is self-contained and exposed only on the auth half of bare mode. Check what the dashboard chat panel and plan_feedback rows expect before removing, and land the replacement handoff first if reviewers would otherwise lose the ability to raise a question.
