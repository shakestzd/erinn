Description

Add internal/guardprofile/ owning the committed profile at .wipnote/guard-profile.yaml. Schema is phase-grouped: guards.{quality,completion,yolo} each a list of {name, cmd, cwd, applies_when}, plus approved:{signature, by, at}. Provide Load(repoRoot) (missing file -> (nil,nil)), Validate, and Signature(profile). CANONICALIZATION (fixed, cross-platform): phases in the fixed order quality,completion,yolo; within each, guards sorted by name; each guard encoded as the NUL-joined tuple name\0cmd\0cwd\0applies_when-normalized; applies_when paths sorted and slash-normalized; the approved block is EXCLUDED from the hash. Signature = "sha256:"+hex(sha256(canonical bytes)). Expose IsApproved(profile) = (Signature(profile) == profile.approved.signature). No gate wiring (slice-2) and no discovery (slice-3) here.
