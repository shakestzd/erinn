Description

defaultSessionName (cmd/wipnote/claude.go) and yoloDefaultName (cmd/wipnote/yolo.go) format the session-label timestamp with time.Now().UTC().Format(20060102-150405), producing a confusing future/offset time (e.g. ...013719 at 21:37 local). Should use local time (time.Now()) so the session name reflects the user's clock.
