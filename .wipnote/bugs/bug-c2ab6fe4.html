Description

The PreToolUse worktree-isolation guard keys off event.PermissionMode == bypassPermissions (Claude Code value). codex --yolo uses --dangerously-bypass-approvals-and-sandbox and does not report that, so the source-leak guard (bug-0ed4e469) does not fire under Codex yolo. The isolation RISK exists on codex --yolo but is uncovered. Needs codex-specific yolo detection in isYoloFromEvent/isYoloWithInheritance so the worktree guard applies. Gemini has no yolo mode.
