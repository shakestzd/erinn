Description

The dedup-heuristic relates_to edge created by maybeAttachDedupRelation carries Properties with a needs-triage-dup tag and a similarity_score — the only confidence signal anywhere in the schema. But internal/lineage.Node has no Properties field and neighborQuery selects only to_node_id, to_node_type and relationship_type, so metadata is never fetched from the DB. The lineage renderer then prints every hop at identical visual weight. Net effect: a text-similarity guess explicitly tagged for human triage displays exactly like a hand-asserted caused_by claim, with no caveat, in the command users read as authoritative. The safeguard exists in the data and is discarded by the code path that most needs it. Surface the tag and score, or visually distinguish heuristic edges.
