Hand a plan-review question back to the CLI session instead of chatting in the dashboard

Todo Medium Priority

Part Of:

  • trk-a951e3c0

Caused By:

  • Deprecate the plan-review chat backend

Description

Replaces the deprecated Claude-only chat backend. When a reviewer hits a question on a slice, the useful move is returning to their live CLI session to discuss it — not talking to a separate headless model with no session context. Likely substrate already exists: slices carry questions with answers, plan_feedback stores dashboard-side state, and wipnote plan read-feedback-yaml already pipes dashboard feedback back. What is missing is the return affordance — making it obvious and cheap to bounce a specific slice question into the session that is actually doing the work. Harness-agnostic by construction, since the CLI session is whatever harness the user is running.
