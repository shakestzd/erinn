Description

Two cleanup paths, both tested. (a) SessionEnd path: if the session ran a spike whose worktree has no commits, no staged/unstaged changes, and no untracked files, auto-complete the spike and remove its worktree. (b) Periodic daemon TTL sweep: same emptiness check, gated on the git worktree lock / heartbeat liveness so live worktrees are never swept. CRITICAL: NEVER remove a worktree with uncommitted or unpushed work without first creating a recoverable snapshot (a deterministically named retained ref; patch under .wipnote as fallback), explicitly avoiding Claude Code #46444.
