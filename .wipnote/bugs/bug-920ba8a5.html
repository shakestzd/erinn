Description

The test maintains a hardcoded inventory of call sites including line numbers, so it fails whenever an unrelated edit shifts a line in the file it inspects. Observed live: an in-flight edit to the reindex command by one agent broke the test for a different agent who had touched nothing related. A test that breaks on line movement reports position rather than behaviour, and its failures carry no information about correctness — which trains people to ignore it, the same erosion as a date-sensitive test. Re-anchor it to something stable such as a symbol, a function name, or a parsed AST query, so it asserts which call sites exist rather than where they sit.
