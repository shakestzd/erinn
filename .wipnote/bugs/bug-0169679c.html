Description

The project instruction table says '.claude/ (anything) — Auto-synced from plugin/ — changes are lost'. That is accurate for the marketplace-installed copy under the user home tree and for generated files inside plugin/.claude-plugin/, but it reads as covering repo-root .claude/agent-memory/, which no build or launch code touches. The imprecision directly caused a false-alarm investigation (spk-2806f862). Fix is one clarifying line noting agent-memory directories are exempt. This is a description correction in a doc that describes rather than configures, not a behavioural change.
