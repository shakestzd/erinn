Commit linking extracts only the first work-item ID, so a commit fixing two bugs links only one

Todo Low Priority

Part Of:

  • trk-08dcbb33

Description

Separate from the regex-strictness issue in bug-d71b7b0c. Even when multiple work-item IDs appear correctly parenthesised on the same commit subject line, the linking check recognises only the first. A commit legitimately fixing two bugs links to one and the other's completion gate refuses for lack of a linked commit, forcing --accepted-advisory. Observed on commit 8bda117d9, whose subject carried both (bug-d0489158) and (bug-f55532ba). Fix by extracting ALL matching IDs per commit rather than the first match.
