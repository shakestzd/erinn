Description

ROOT CAUSE CONFIRMED BY DIRECT MEASUREMENT, and it inverts the framing. Canonical HTML declares implemented-in edges targeting 156 distinct session identifiers. Exactly 3 of those exist in the sessions table, and a 40-target sample of the missing 153 found zero present on disk in any form — the sessions were pruned or never ingested. The 82 surviving edges are those pointing at the 3 live sessions. So the target-validity gate is not hiding a relationship type; it is correctly refusing dangling references, exactly as designed. The REAL defect is a policy gap the gate exposes: work items are permanent and git-tracked, sessions are ephemeral and prunable, and the edge bridging them is declared in the permanent artifact. When the session ages out, the gate silently erases the provenance record that the work was ever implemented in a session at all — which contradicts the causal-lineage mission. DECISION NEEDED, then implementation: either preserve edges whose source is canonical HTML even when the session target no longer resolves, marking the target unresolvable so queries can distinguish tombstones from live nodes, or accept that provenance decays with session retention and record that as an explicit, documented property rather than an accident. Recommendation is preserve-with-tombstone: the edge itself is canonical and git-tracked; only its target is ephemeral. Acceptance Criteria A deliberate, recorded policy on edges to pruned sessions, implemented in the gate, with a test distinguishing a tombstoned target from a dropped edge.
