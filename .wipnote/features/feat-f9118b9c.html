Description

compliance auto currently only diffs spec against code — it asks whether the diff matched the spec, never whether the result worked. Its diff builder uses only GetCommitsByFeature and ListFilesByFeature and never touches gate_records, otel_signals or agent_events. Join gate pass/fail history and per-work-item error rates so compliance scores outcome as well as intent. Separately, recommend prioritises purely on work-item metadata (status, priority, track) and is blind to thrash — it cannot deprioritise or flag a work item whose sessions show high error and retry rates. Depends on the per-work-item rollup layer landing first.
