Description

New cmd/wipnote/recap.go cobra command. Accepts a work-item id positional, or --range <gitrange>, or --session <id>. Calls the collector (slice-1), renders via recaptmpl (slice-2), writes .wipnote/recaps/recap-<id>.html, and commits it atomically via a commitRecapArtifact helper modeled on commitWipnoteArtifact/commitPlanChange (git -C <repoRoot> absolute path, no host paths in body). Wires a lineage edge recap relates_to/derived_from the work item.
