post-commit hook doesn't link commit to work item by parsing the ID from the commit message (fallback when no active session item)

Todo Medium Priority

Part Of:

  • trk-0677c709

Description

Commit-to-workitem linking depends on the session's active work item at commit time. When a commit is made by a session with no active item (e.g. a delegated committer subagent), the live post-commit hook links nothing, even when the commit message names the work item ID explicitly. Only the batch 'ingest commits' picks it up. Fix: post-commit hook should parse a work-item ID from the commit message and link as a fallback when no active item is set. Surfaced while completing bug-900f6655.
