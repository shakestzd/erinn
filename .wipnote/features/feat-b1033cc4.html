Add cmd/wipnote/guard_init.go: ensureGuardProfile (projectRoot) that on each interactive launch checks for an APPROVED profile and, if absent AND interactive (isTerminal(), cmd/wipnote/relevant.go:100), presents Propose()'s output for approve/edit, writes .wipnote/guard-profile.yaml with approved:{signature,by,at} (by = git config user.name or session identity; at = now), and commits it via runGitMutation. Wire ensureGuardProfile into the launcher bootstraps right beside the OTel collector spawn: cmd/wipnote/claude.go (~line 608-616 alongside ensureServeForDashboard / spawnSessionCollector), plus yolo.go, dev.go, codex_launch.go, gemini.go.
