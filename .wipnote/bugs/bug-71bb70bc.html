Session reaper marks sessions completed only in the projection, never the ledger

Todo High Priority

Part Of:

  • trk-2c55adea

Description

The reaper in core/hooks/session_end.go updates session status in the ephemeral projection rather than the canonical sessions ledger. Same class as bug-aa0bbd43, which was fixed for session end. Consequence: stale sessions stay open in sessions-ledger.html, and every daemon restart re-hydrates the still-open ledger and re-closes the same claim episodes, indefinitely. The reaper's claim-ledger and collector work is real and should be retained; only the session-status write is misdirected.
