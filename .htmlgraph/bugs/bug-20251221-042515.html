Properly support querying and filtering both file-based and directory-based tracks ## Tests Added Created comprehensive test suite in tests/python/test_track_loading.py: - test_load_directory_based_track: Verifies directory tracks load correctly - test_load_file_based_track: Verifies file tracks still work - test_load_mixed_tracks: Verifies both formats coexist - test_track_where_query: Verifies filtering works - test_track_get_by_id: Verifies get by ID works All tests pass. The fix is backward compatible and doesn't break any existing functionality.
