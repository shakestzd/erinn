Description

wipnote's causal lineage is retrospective: something happened, what caused it. Investigate whether the same graph-native architecture could support prospective reasoning: we want behaviour B, what interventions do we believe will cause it, and how will we know if those causal assumptions held. Levels under consideration: (1) explicit causal hypotheses, (2) expected-vs-observed lineage diffing, (3) counterfactual queries, (4) causal knowledge learned across sessions. Deliverable is an investigation document that tries to FALSIFY the idea, not validate it - specifically whether ordinary planning plus tests already achieves the same result with less complexity. Must distinguish observed facts from interpretation, hypothesis and proposed design, with file citations for every claim about the repo.
