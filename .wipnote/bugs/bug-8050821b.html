Learning cards silently collide when two work items touch the same file paths

Todo Medium Priority

Part Of:

  • trk-2c55adea

Description

Completing feat-2bd74c58 with --learning printed 'warning: failed to create learning card: card with the same path glob set already exists: same paths as learning-bug-3af1d597' and dropped the learning. The two items were fixed in the same commit and so share a path glob set, which is normal for a multi-fix commit. Effect: the second and subsequent learnings from any commit that closes several items are lost, and only a warning on stdout marks it - the completion still reports success. The learning that was dropped is the most transferable one from that work. Suggest merging into the existing card, appending a second learning to it, or disambiguating the glob set by work item id rather than refusing.
