Cross-platform build support (Windows): build-tag Unix-only syscall usage

Todo Medium Priority

Description

wipnote does not build for Windows today: GOOS=windows GOARCH=amd64 go build ./... fails on unguarded Unix-only syscall usage. Affected (pre-existing, predating trk-b1d06a84): internal/agent/session_family.go, internal/otel/materialize/materialize.go, internal/otel/sink/ndjson (syscall.Flock/LOCK_EX/LOCK_UN), and added on this branch: internal/commitqueue/outbox.go (syscall.Flock) and cmd/wipnote/git_lock_repair.go (syscall.Stat_t.Ino in inodeOf). Fix approach: route advisory file locking through the maintained cross-platform github.com/gofrs/flock wrapper (already a dependency, used by cmd/wipnote/git_mutation_lock.go) instead of raw syscall.Flock; move inode extraction behind platform build-tagged files (inode_unix.go //go:build unix returning Stat_t.Ino, inode_other.go fallback returning 0 so the git-lock same-file check degrades to mtime+age). Add a GOOS=windows go build check to CI to prevent regressions. Acceptance: GOOS=windows go build ./... succeeds; go test ./... still green on Linux.
