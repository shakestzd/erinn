Claude Code docs state bare mode skips discovery of hooks, skills, plugins, MCP servers and project instruction files, and that it will become the default for -p in a future release. wipnote runs claude -p for compliance auto-grading. When that default flips, that flow stops emitting data with no error. Time-sensitive but needs no external citation to act on — decide now whether to pin the non-bare flag explicitly or move off -p.
