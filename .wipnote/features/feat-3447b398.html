Promote agent_id and parent_agent_id to first-class UnifiedSignal fields

Todo High Priority

Part Of:

  • trk-1db7bf72

Description

Claude Code emits agent_id on subagent llm_request spans and parent_agent_id at nesting depth greater than one, and wipnote already ingests those spans — it forces telemetry on by default and its ClaudeAdapter parses the span tree with real TraceID, SpanID and ParentSpan. But UnifiedSignal in observe/otel/signal.go has no AgentID or ParentAgentID field, so the adapter drops both into the untyped RawAttrs map and no downstream code reads them back. Promote them to typed fields. Cheap: the data is already arriving on every session.
