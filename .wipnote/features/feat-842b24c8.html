Description

Extend the daemon write protocol so any non-daemon process can submit an arbitrary parameterized write over the local IPC. Add OpTypeSQL to the DerivedOp struct (core/daemon/apply/apply.go) carrying SQL string + Args ([]any, JSON-encoded). The daemon's apply loop executes it (parameterized, RetryOnBusy-wrapped) on its single writable handle. Add a client helper apply.RouteSQL(projectRoot, sql, args...) bool (core/daemon/apply/cli_route.go) that wraps WriterClient.SubmitOrSpawn (auto-spawns the daemon, ~2s bounded) and returns true on ack. Keep the existing typed routes (RouteSessionInsert/Status, SubmitDerivedEvent) untouched for the hot paths.
