SessionEnd discards five of its six writes

Todo High Priority

Part Of:

  • trk-2c55adea

Description

Of the six writes SessionEnd performs on every session close, only the session-status update is mirrored to canonical storage via recordSessionLedgerClose. Five are discarded at process exit: the transcript_path and end_reason update, features_worked_on, the handoff notes written by persistSessionEndHandoff, the lineage-trace completion, and the claims release. None has a canonical companion — sessionledger Enrichment carries no fields for handoff notes, transcript path, or features worked on, and Enrich is never called from the session-end hook at all. Two are doubly moot because their inputs read agent_events, which no hydration pass populates, so the computed values are empty before the dead write happens. Net effect: SessionEnd durably records only that the session ended.
