Description

The durable resolution of the graph-edges question. The table is not removed — the performance case died by measurement and the in-memory rewire cannot serve node types that live in telemetry. Instead the table is formally a materialized derivation over four canonical sources: work item and plan HTML for human-declared edges, plan YAML for slice ordering, the architecture ledger for learning links, and session records for reversed implements edges. All four derivations already run inside reindex and are idempotent, verified by reading the passes. Two pieces make the contract enforced rather than assumed. First, implement the pruned-session policy from the gate bug: preserve edges whose source is canonical HTML when the session target no longer resolves, marked as tombstoned, so provenance survives session retention. Second, extend the edge census test to compare canonical declarations plus the documented derivations against the index — today it pins only rebuild idempotence, which is why an 828-versus-82 gap survived it for months. When both land, any writer that is not a reproducible derivation, and any future divergence in either direction, fails a test instead of accumulating silently. This closes the drift class that motivated removing the table, without removing it.
