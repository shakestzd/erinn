Description

Durable systemic fix for harness hook-contract drift. Add a hookEventContractSpecs table in internal/pluginbuild (analogous to agentFrontmatterFieldSpecs) classifying each hook event as observational / additive-controlling / replacement-on-registration, and a build/test-time check that FAILS when a replacement-classified event is registered with an observe-only handler (the WorktreeCreate class of bug, bug-80b27913). Also flag handlers returning a shape an event does not support. This catches drift at build time instead of in production.
