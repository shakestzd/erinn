wipnote trace --tests: show test files touched by a work item

In Progress Medium Priority

Part Of:

  • trk-08dcbb33

Description

Add a --tests flag to 'wipnote trace <feat-id>' that filters the existing feature_files association down to _test.go files touched by the work item, reusing the existing feature-trace data path (dbpkg.ListFilesByFeature) rather than new ingestion. Output must state the touched-by-not-owned-by semantics explicitly (feature_files is UNIQUE(feature_id, file_path), many-to-many) — this answers 'which test files did this item touch', not 'which tests verify this item'. Supports --json. Also add the cheap inverse (given a test file, which work items touched it) if it is a few lines; otherwise report feasibility only.
