Description

The derived SQLite index is selected onto the ephemeral container tmp filesystem because the user cache dir is overlayfs (WAL-unsafe), so container restarts wipe gate records and claim/liveness state. Add a persistent WAL-safe candidate (user local-share dir) preferred over tmp ONLY when the cache dir fails the WAL-safety probe, so host users are unaffected and containerized users get durability with no journal-mode change (no contention regression). Add a regression test; correct the stale cache-path claim in AGENTS.md.
