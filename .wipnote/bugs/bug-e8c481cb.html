Description

The repository states there is no verified canonical upstream documentation set for Antigravity and that the port translator should be treated as the executable spec. That is now out of date. A Google documentation portal exists and was verified by direct fetch, covering Antigravity 2.0 and the agy CLI, announced at Google I O in May 2026. The port translator is still annotated as verified against agy v1.0.8 while v1.1.11 is documented. Two consequences. First, the harness monitoring section names Antigravity as having no doc set, which is no longer true and should be re-verified against the real portal. Second, the audit found Antigravity exposes no per-subagent identity in hooks, no input or environment rewrite mechanism, and no telemetry emission at all — the last confirmed by an upstream issue where standard environment variables produced no export. So the agent identity seam is not implementable on Antigravity today on any axis, and the generated hook commands hardcode a single static identity for every subagent, meaning all Antigravity activity attributes to one identity with no differentiation. Record that as blocked upstream rather than shipping a mechanism that would silently do nothing.
