exec_worktree_path and session handoff notes have no canonical home

Todo Medium Priority

Part Of:

  • trk-2c55adea

Description

session_start.go writes ExecWorktreePath, handoff_notes, recommended_next, blockers and branch into the sessions table only. Post feat-fc3cc9e0 that table is a per-process in-memory projection, so those fields are discarded when the hook process exits. The canonical sessionledger.Record is deliberately slim (session id, harness, project dir, start, end, archive path, events) and carries none of them. Effect: wipnote continue can no longer resume into a prior worktree or replay handoff notes; it degrades to a fresh continuation with a missing-worktree warning. Masked today because the launcher passes intent.WorktreePath, which resolveContinueWorktreePath prefers over the stored value. Fix requires deciding whether these belong in the session ledger or in a separate canonical per-session state artifact.
