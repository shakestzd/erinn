Description

The port's Codex agent translation uses a hardcoded alias-to-model map and returns an empty string for an unmapped alias rather than erroring, so a generated agent TOML can ship with no model at all. This is a resilience defect independent of whether the currently mapped ids are stale — treat the two concerns separately. Fail loudly on an unknown alias.
