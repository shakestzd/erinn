Description

compliance_auto.go was passing --system to claude, which is not a recognized flag (only --system-prompt exists); every real non-stubbed headless grading invocation failed with 'unknown option'. Fixed under bug-48b023e5, but the reason it shipped is the durable problem: compliance_auto_test.go only ever stubs the headlessInvoker variable and never exercises realHeadlessInvoker against the real binary, so the constructed argv is untested. Any flag drift in the harness CLI is invisible. Add a test that asserts the built argv against the installed binary's accepted flags, or at minimum a golden-argv test so a rename is caught at CI rather than at runtime.
