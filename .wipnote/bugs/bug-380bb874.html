Description

Distinct from bug-cbdb06ca (URL guard). The activity feed visibly disappears/reappears: handleSSE debounces a full this.load() on every SSE message (event-tree.js:781-783, 500ms), and load() sets innerHTML to the 'Loading activity…' empty-state at event-tree.js:92 BEFORE the fetch resolves — a clear-then-refetch flash on every live event. With an active session emitting steady events the feed blanks ~every 500ms. Not caused by commit 9e4add2ee (the _loaded guard prevents re-entry). Fix: only render the loading placeholder on first load (when this.turns is empty); keep existing content visible during SSE re-fetches, replacing the DOM only when new data arrives in render().
