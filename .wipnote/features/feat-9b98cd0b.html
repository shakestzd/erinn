Description

Add headless passthrough modes to the launchers so orchestrators delegate via wipnote: wipnote codex exec '' (wraps codex exec --json, captures the documented JSONL event stream — thread.started/turn.completed/item.* — and ingests it as a wipnote session with attribution and token usage) and wipnote gemini exec '' (wraps gemini -p --output-format stream-json similarly; hooks already fire so ingest is belt-and-braces plus usage stats). This gives live-hook capture where supported and transcript ingest everywhere, making external CLIs first-class observed subagents.
