writer.sock bind fails when project path exceeds unix sun_path limit (~108 bytes)

Todo Medium Priority

Part Of:

  • trk-13e39042

Description

Surfaced by CI run 27291049822: binding /.wipnote/writer.sock fails with 'bind: invalid argument' when the absolute socket path exceeds the Linux unix-domain sun_path cap (~108 bytes). Any real project nested deeply enough hits this — daemon/writer features silently break. Mitigations to evaluate: bind via a short relative path after chdir, openat-style bind tricks, hash-shortened socket dir under XDG_RUNTIME_DIR or /tmp keyed by project hash (mirroring the per-user cache layout), or abstract socket namespace (Linux-only). Detect at startup and emit a clear error instead of bind: invalid argument.
